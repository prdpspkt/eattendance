Setting up a push device
  1. On the terminal: Menu → Comm. → Ethernet → Cloud Server / ADMS (some firmware calls this Server Setting).
  2. Server address: this site's hostname. Port: 80.
  3. Leave Enable Proxy Server off, and HTTPS off unless the firmware handles TLS properly.
  4. Save and reboot the terminal.
  5. It calls home within seconds and appears here. Tick Active to accept its data.
Registering here is optional. If you skip it, the terminal adds itself on first contact as Unregistered device <SN> and waits for you to activate it — which is often easier than reading the serial off the unit.
Setting up a pull device
  1. Connect the terminal to the network and note its address from Menu → Comm. → Ethernet.
  2. Confirm the server can reach it — the port is 4370 by default.
  3. Save, then use Test Connection on the device page.
  4. Use Sync Users to import the enrolled users.
Pull mode needs the server to open a connection to the terminal, so it does not work across NAT or from a remote branch without a VPN or port forwarding. Prefer push mode for anything off the local network.
